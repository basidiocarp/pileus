# Recommended Skills for `pileus`

Pileus is a public-facing React + TypeScript + Vite website built with Mantine. Keep the active skill set small and focused on frontend implementation, visual quality, accessibility, and verification.

## Primary Set

Use these by default for normal website work:

- `react-patterns`
- `typescript`
- `frontend-patterns`
- `component-architecture`
- `responsive-design`
- `accessibility`

## Secondary Set

Use these when the task specifically needs them:

- `frontend-performance` - profiling render cost, bundle size, layout work, or asset loading
- `systematic-debugging` - investigating broken behavior before patching
- `clarify-requirements` - resolving ambiguous scope, content, or design intent
- `code-review-process` - reviewing a completed change before merge

## Notes

- This repo does not currently use Next.js App Router, Auth.js, GraphQL, REST API boundary layers, Zustand, ECS, OpenTelemetry, Docker, or project-local GitHub Actions workflows.
- Testing skills were removed because there is no Jest/Vitest setup in `package.json`. Add focused testing guidance back only when the project adds a test runner.
