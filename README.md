# Pileus

The public-facing marketing and documentation website for the [Basidiocarp](https://github.com/basidiocarp) ecosystem.

## What it is

Pileus is a React + TypeScript + Vite app built with [Mantine](https://mantine.dev). It serves as the entry point for users discovering the Basidiocarp AI coding agent infrastructure toolkit.

## Development

```bash
npm install
npm run dev        # start dev server
npm run build      # production build
npm run preview    # preview production build
```

## Stack

- **React 19** with React Compiler
- **TypeScript 6**
- **Vite 8**
- **Mantine** — UI component library
